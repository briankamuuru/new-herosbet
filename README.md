# Herosbet - Android Betting Tips & VIP Predictions

A native Android application written in Kotlin and Jetpack Compose, rewritten from Flutter while preserving all core betting tips features, categories, and business logic.

## Features

- **Daily Sure Tips**: High confidence free daily football betting predictions.
- **VIP Odds Categories**:
  - **3 ODDS VIP**: Safe banker 3.0+ multi-match slips.
  - **6 ODDS VIP**: High-multiplier 6.0+ combination predictions.
  - **Maxbetters Special VIP**: Exclusive high-stake selections.
- **Live Ticket Data**: Dynamic match tickets with dates, leagues, team matchups, betting tips, scores, and calculated total odds.
- **Paywall & VIP Management**: Subscription options (Weekly Fixed VIP, Monthly Fixed VIP) with instant demo unlock mode for testing.
- **Official Telegram Integration**: Direct one-tap link to join the official community channel (`@herosvipking`).
- **Privacy Policy**: In-app policy viewer and external browser launcher.
- **Offline & Fallback Resilience**: Built-in caching ensuring immediate responsiveness even with unstable network connectivity.

## Tech Stack

- **Kotlin & Jetpack Compose**: Material Design 3 UI, declarative layout, edge-to-edge support.
- **Architecture**: MVVM with Kotlin Coroutines, StateFlow, and clean separation of concerns.
- **Gradle 9.3.1 & AGP 8.9.0**: Optimized Android build configuration.
- **Min SDK**: 24 | **Target SDK**: 35
